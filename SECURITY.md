# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately via [GitHub Security Advisories](https://github.com/TheRoks/pnpm-audit-promote/security/advisories/new).

We aim to acknowledge reports within 5 business days and to issue a fix or
mitigation guidance for confirmed issues as soon as possible.

## Supported versions

Only the latest minor release line receives security fixes.
